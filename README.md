# 🍳 PantryPal AI – Recipe Preparation Agent

PantryPal AI is a smart recipe preparation web application that helps users discover delicious recipes using the ingredients they already have.

The application analyzes available ingredients along with user preferences such as dietary requirements, cooking time, and difficulty level to recommend the most relevant recipes.

## 🚀 Features

- 🥬 Add and manage available ingredients
- 🔍 Smart ingredient-based recipe matching
- 🍽️ Personalized recipe recommendations
- ⭐ Displays the top 5 most relevant recipes
- 🥗 Dietary preference filtering
- ⏱️ Cooking time filtering
- 📊 Difficulty level filtering
- 👩‍🍳 Complete step-by-step cooking instructions
- 🔄 Smart ingredient substitutions
- 💡 Personalized cooking tips
- ♻️ Food waste reduction suggestions
- ❤️ Save favorite recipes
- 🕒 View recent ingredient searches
- 💾 Uses LocalStorage to save favorites and recent searches

## 🧠 How It Works

1. **Add Ingredients**  
   Enter the ingredients currently available in your kitchen.

2. **Set Preferences**  
   Select your dietary preference, cooking time, and difficulty level.

3. **Find Recipes**  
   PantryPal AI compares your ingredients and preferences with the available recipe database.

4. **Get Personalized Recommendations**  
   The application displays the top 5 most relevant recipes.

5. **View Full Recipe**  
   Get detailed cooking instructions, ingredient analysis, substitutions, cooking tips, and food waste reduction suggestions.
